# Manual AI Prompt Library — COP Visibility Testing

**Purpose:** A vetted library of ~120 prompts to paste into ChatGPT, Perplexity, Google AI Mode, Claude, and Gemini for tracking whether COP gets cited in AI answers.

**How to use:**
1. Pick a query from a funnel stage below.
2. Paste it (exactly) into the engine you're testing.
3. Read the answer and check the cited sources.
4. Log in the tracker dashboard: Was COP cited? At what rank? What domain was #1?
5. Run the full library quarterly; run high-priority queries (★) monthly.

**Engines to test against each quarter:**
- ChatGPT (chatgpt.com, Search mode + plain chat with browsing on)
- Perplexity (perplexity.ai, Auto + Pro)
- Google AI Mode (google.com, the AI Mode toggle on the SERP)
- Google AI Overviews (regular google.com search — count whether an AI Overview generates and whether COP is cited)
- Claude (claude.ai with web search on)
- Gemini (gemini.google.com)

**Notation:** ★ = highest-priority prompts to test monthly. ⓐ = where COP currently ranks well (per May 2026 baseline). ⓖ = whitespace opportunity — re-test after the relevant content ships.

## 8. Tracker logging spec (for the dashboard)

For each prompt run, log to the artifact dashboard:

| Field | Format | Notes |
|---|---|---|
| date | YYYY-MM-DD | |
| prompt_id | Section number + index, e.g. "1.5" | Section 1, prompt 5 |
| engine | enum | chatgpt / perplexity / google-ai-mode / google-aio / claude / gemini |
| cop_cited | bool | Was co-ownership-property.com cited in the answer? |
| cop_rank | integer or null | If cited, what citation number / rank |
| cop_url | string or null | Which COP URL was cited |
| top_cited_domain | string | The #1 cited source |
| top_3_domains | string | Comma-separated |
| competitor_count | integer | How many competitors (Pacaso/MYNE/Vivla/August/Kocomo) cited |
| notes | string | Optional free text |

Run cadence:
- ★ prompts: monthly (≈ 75 prompts × 6 engines = 450 runs/month, ~15min/run)
- All prompts: quarterly (≈ 120 × 6 = 720 runs/quarter)
- Smart partial: run 25 random non-★ prompts every two weeks alongside the monthly ★ sweep, giving full library coverage every ~3 months without a single huge testing day.

Time budget: 2–4 hours per monthly cycle, 6–10 hours per quarterly sweep. Worth automating Perplexity + ChatGPT via API once the dashboard is wired (free tiers exist for both).

## 9. Things to watch for in the answers

Beyond "did COP get cited", note:

- **Citation co-occurrence patterns.** When COP is cited alongside Pacaso, that's the co-occurrence signal you want — LLMs build category-defining brand clusters from these pairings. Track which competitors COP shows up next to.
- **Which COP URL is cited.** Destination pillar pages? Blog posts? FAQs? The pattern shifts your content investment priorities — if Spain pillar is cited 10× more than the Mallorca pillar, deepen Mallorca; if blog posts win, deepen the blog.
- **Quotation patterns.** When an engine *quotes* COP text, that's the highest-quality signal — the model has chosen our exact phrasing. Note which passages get quoted; structure more content like that.
- **Refusal patterns.** When an engine says "I don't have enough information about co-ownership-property.com" — that's a training-data gap, not a retrieval gap. Solved by §0.1 (unblock crawlers) and §5.4 (brand mention density on third-party surfaces).
- **Hallucinations.** Engines sometimes invent details ("COP is based in Madrid"). Note these — they're signals about what's in training data and where it's wrong.
