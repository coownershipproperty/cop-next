# co-ownership-property.com — robots policy
# We welcome legitimate web and AI crawlers. Editorial content, destination
# guides, FAQs, blog posts and property listings are open for crawling,
# indexing, training and citation.
#
# The private surfaces below are excluded from crawling. Note the file had no
# Disallow line at all until 10 Sep 2026, and its header claimed auth-gated
# areas lived under /api/admin/* — but /admin/ is a 16-route page tree, and
# /partner/, /gallery/ and the preview URLs are pages too. Robots exclusion is
# not a security control; it stops these being crawled and indexed, nothing
# more. Real protection is Supabase RLS plus the app's own auth.
#
# IMPORTANT — the public JSON feeds live under /api/ and MUST stay crawlable,
# so /api/ is not blocked wholesale; only its private subtrees are.
#
# Also important: under the robots standard a named User-agent group REPLACES
# the * group entirely — it does not inherit from it. So every rule below is
# repeated for the AI crawlers in a single consolidated group. If you add a
# Disallow, add it in BOTH places or it will not apply to them.

User-agent: *
Disallow: /admin/
Disallow: /auth/
Disallow: /partner/
Disallow: /partner-hub/
Disallow: /gallery/
Disallow: /favourites/
Disallow: /unsubscribe/
Disallow: /previews/

Disallow: /api/preview/
